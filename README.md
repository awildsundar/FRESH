A 3D ARPG inspired by TWEWY, Persona 5, and Bomb Rush Cyberfunk!

## What this is
<img width="817" height="460" alt="image" src="https://github.com/user-attachments/assets/6ec2fdf6-f1d3-4c98-8124-aef09b4aec86" />

This is a 3D action RPG where you deal damage using intra-character combos! If you have ever played TWEWY on the DS, it is inspired by the combat of that game, adapted for modern devices. Players will have to switch between characters on the fly to stack status effects on enemies, and if they manage to perform enough combos, they can unleash a massive arena-wide attack! The game is being developed in Godot 4.7, models are being created in Blender 4.1, and music will be created in FL Studio.

Currently, the game is extremely bare bones, only the Quest, Save/Load, Dialogue, Shop, and Combat systems have been implemented in very basic forms. However, as production continues I hope to expand these systems into fully-fledged game mechanics!

## How to Play
Go to the itch.io page: https://awildsundar.itch.io/fresh-wip, and download the FRESH iteration 1.exe file, then just run it!
